# AI 提示词优化器

源自 影策 Open AI Canvas 开源社区贡献插件（MIT License）。在创作页以及图片、视频节点的提示词编辑器中提供「润色」入口，结合当前选定的文本模型与目标生图/生视频模型特性，将模糊想法整理成可执行、可对比、适配模型协议的提示词。

## 功能特性

- **五种优化模式**：扩展想法（`expand`）、精修已有（`refine`）、强化风格（`style`）、适配模型（`model-adapt`）、结合参考素材（`reference`）。
- **模型族定向适配**：针对 Gemini / Imagen、OpenAI、Grok、Seedream / 即梦、FLUX、SDXL、Midjourney、Ideogram / Recraft、Seedance、Veo、Kling 等主流模型自动匹配提示词结构。
- **不自动覆盖原文**：生成主提示词与最多 2 个备选版本并列出改动说明与合理假设，只有用户主动点击采用后才写入输入框。

## 使用说明

1. 安装并启用本插件。
2. 在 BeefTV「设置 -> 模型服务」中配置可用的文本/多模态理解模型。
3. 在创作页或画布图片、视频节点的提示词面板中点击「润色」即可打开提示词优化抽屉。

## 所需权限

- `ai.text`：调用当前配置的文本/多模态理解模型生成润色建议。
