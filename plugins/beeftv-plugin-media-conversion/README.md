# 媒体转换节点

连接图片到转换节点后，可以在节点内选择灰度图、Canny 边缘、AI 线稿、深度图或姿态骨架；连接视频时，灰度图和 Canny 边缘会先提取视频首帧再处理。

- **普通图像算法**（灰度图、Canny 边缘）：在浏览器本地直接完成像素计算，无需额外依赖。
- **AI 线稿**：使用本机 ControlNet Aux 预处理模型，首次运行需要加载模型。
- **深度图**：使用本机已安装的 Depth Anything V2 Small 模型。
- **姿态骨架**：使用 ControlNet Aux 的 OpenPose 人体预处理模型；未检测到人物时会跳过并提示。
- **透明抠图 / 视频高级模型**：仍在验证，选择时会明确提示不可用。

该插件只读取当前节点的媒体输入，并把结果保存回当前画布节点的本地素材存储，供下游生成节点继续引用。

## 所需权限与运行依赖

- `canvas.read` / `canvas.write`：读取上游图片或视频输入，并将转换状态与结果写入节点 `metadata.mediaConversion` 供下游生成节点引用。
- `media.read`：读取待转换图片与视频首帧资源。
- **本机预处理模型服务**：AI 线稿、深度图与姿态骨架需连接本机预处理服务；服务未启动时可运行 `start-beeftv-local.cmd` 或点击节点内重连恢复。
