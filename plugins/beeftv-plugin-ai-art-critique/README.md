# AI 审美批改

在画布中添加 **AI 审美批改** 分析节点。将任意图片节点连接到该节点后，系统会调用已配置的视觉理解文本模型，依次完成场景理解、构图/色彩/光线/结构四路并行审核、聚合去重、坐标定位、独立复核以及局部修图提示词生成，并在原图上以 SVG 交互标注展示批改报告。

## 主要功能

- **多维审美 Rubric (`2026-08-v1`)**：覆盖构图与视觉层级、色彩关系、光线与曝光、比例结构与透视四大维度，克制区分确定性问题（`issues`）与可选风格方向（`options`）。
- **可视化区域定位**：支持归一化 `box`、`point`、`points`、`polygon` 与 `global` 定位；模型定位不确定时按文字位置描述映射参考区域。
- **局部修图提示词**：由 AI Prompt Writer 结合问题与位置区域生成可直接复制用于局部编辑的自然语言提示词。
- **非破坏式输出**：分析结果仅保存在节点 `metadata.pluginData.artCritique` 中，不会修改原始输入图片。

## 所需权限

- `canvas.read` / `canvas.write`：读取上游图片节点并保存分析状态与报告。
- `media.read`：读取或检查待分析的原图数据。
- `ai.text`：调用当前配置的文本/视觉理解模型运行多阶段批改流程。
- `generation.run`：通过宿主审批执行器提交多阶段视觉分析任务并获取真实费用报价。
